WEEK 4 - PERFORMANCE OPTIMIZATION IN PYTHON

Project: Count distinct values in a generated list.
Files: original.py (baseline), optimized.py (set-based), benchmark.py (timeit + cProfile), test_performance.py (unit tests), benchmark_results.txt (captured output), and Word report.
Requirements: Python 3.8+; standard library only.
Run from this folder:
    python benchmark.py
    python -m unittest test_performance.py
The generated dataset contains 12,000 integers and 1,500 distinct values. No external input files are required.
